# Customer Churn AI Analysis

AI-powered customer churn analysis system combining Python, SQL, Power BI, and Google's Gemini AI to identify why customers leave and generate automated business insights.

## Dashboard

![Dashboard](Screenshot%202026-09-23%20102140.png)

## What This Project Does
- Cleans and analyzes a 7,000+ record telecom customer dataset using Python (Pandas)
- Stores and queries data in MySQL using subqueries, CASE statements, CTEs, and window functions
- Uses Google Gemini AI to automatically generate a written business report with insights and recommendations
- Visualizes key findings in an interactive Power BI dashboard

## Key Findings
- Overall churn rate: 26.54%
- Month-to-month contract customers churn at 42.71% — nearly 15x higher than two-year contract customers (2.83%)
- Fiber optic customers churn the most among internet service types (41.89%)
- Churned customers pay ₹13/month more on average than retained customers

## Tools Used
Python (Pandas), MySQL, SQL, Power BI, Google Gemini API
